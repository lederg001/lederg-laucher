# LEDERG STALKER Launcher

Чёрно-красный лаунчер для клиентской сборки Minecraft Forge 1.12.2.

## Что делает
- скачивает ZIP клиента по публичной ссылке Google Drive и распаковывает его в отдельную папку в `%LOCALAPPDATA%\LEDERG Launcher\client`;
- проверяет целостность ZIP и блокирует небезопасные пути архива;
- выбирает профиль `Forge 1.12.2`;
- задаёт автоматическое подключение к `LEDERG05.aternos.me:26820`;
- запускает TLauncher, чтобы пользователь мог авторизоваться через используемый им аккаунт/метод.

**Первый запуск:** требуется указать публичную ссылку на ZIP-файл Google Drive с доступом «Все, у кого есть ссылка». Ссылки на папки Drive не подходят — нужен именно ZIP-файл. Ссылка сохраняется локально; в репозиторий она не отправляется.

## Сборка
На Windows:
```powershell
py -m pip install -r requirements.txt
py -m pytest -q
py -m pip install pyinstaller
pyinstaller --clean --noconfirm --onefile --windowed --name LEDERG-Launcher --add-data "launcher_config.json;." launcher.py
```

GitHub Actions собирает Windows EXE, запускает тесты и публикует EXE в GitHub Releases.

## Моды и границы ответственности
Клиентская сборка включает базовые моды из исходного клиента и VanillaFix 1.0.10-150. Отключение спавна враждебных мобов — серверная настройка; один лишь клиентский модпак не может гарантировать это на Aternos.

## Приватность
В распространяемый ZIP не включаются локальные миры, логи, сохранённый список серверов и файлы аккаунтов/профилей TLauncher. Логины, пароли и токены лаунчер не собирает и не отправляет.
